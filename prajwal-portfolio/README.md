# Prajwal Mandaokar, Portfolio

A responsive, interactive portfolio built from my resume.

## Features
- Minimal dark theme with neon cyan and pink accents
- Smooth scroll-reveal animations and hover transitions
- Typing role animation, animated stat counters
- Skill filter chips and sticky, shrinking navbar with active-link highlight
- Mobile menu, cursor glow, and reduced-motion support

## Project structure
```
prajwal-portfolio/
├── index.html
├── css/style.css
├── js/main.js
└── README.md
```

## Run it locally
1. Open the folder in VS Code.
2. Install the **Live Server** extension (optional but recommended).
3. Right-click `index.html` and choose **Open with Live Server**, or just double-click `index.html`.

## Customize
- Colors: edit the variables under `:root` in `css/style.css`.
- Content: edit the sections in `index.html`.
- Typing roles: edit the `roles` array in `js/main.js`.
